# Footscray Dental Studio website

Static site with working contact forms and an admin panel, deployed on Vercel.

- **Deploy and configure:** see `DEPLOYMENT_NOTES.md`
- **Run locally:** `cp .env.example .env`, then `npm run dev`
- **Tests:** `npm test` (with the dev server running)
- **Admin panel:** `/admin/`

Pages live in `site/` (generated by the Python scripts in `build/`), editable content in `content/site.json`,
the build step in `build/apply-content.js`, the API in `api/`.
